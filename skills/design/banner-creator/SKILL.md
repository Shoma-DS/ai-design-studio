# バナー Creator

## 使う場面

ユーザーが「バナー」を作りたいと明示したときに使う。

## 参考資料

- `references/banner-design/README.md` — バナーデザインの作り方・チェックリスト（構成/配色/文字/視線誘導/最終確認）。制作前・仕上げ確認時に参照する。

## 手順

1. 目的、媒体、サイズ、ターゲット、トーン、必須コピーを確認する。
2. 明示されていない重要条件だけ質問する。
3. **勝ちパターンのリサーチ（2ステップ制作法、2026-07-30追加）**：業種・ジャンルの広告トレンドが不明瞭な場合、コピー・構成を作る前に以下の2段階で進める（X投稿の「2回だけコピペプロンプト」をこのリポジトリの生成基盤向けに翻案したもの）。
   1. **分析**：`WebSearch`で「〇〇広告の勝ちパターンを最新情報から分析」する。日本語＋英語の両方で検索し（例:「〇〇 広告 バナー デザイン 勝ちパターン 2026」「〇〇 ad creative best practices trends 2026」）、必須要素（名称・価格・期間限定訴求等）、配色・トーンの定石、最新のメッセージング傾向（例: スペック訴求より感情訴求を先にする）を把握する。この分析結果を、以降のコピー・構成の基準として扱う。
   2. **反映して生成**：その勝ちパターンを手順4のコピー・構成、手順5の画像プロンプトに反映する。情報を詰め込みすぎない、スマホで一瞬で伝わる量にする、極小文字は使わない、を必ず満たす。サイズは指定が無ければ正方形（1:1）を基本にする（SNS/Web広告で汎用性が高いため）。
4. コピーと構成を作る。
5. `skills/design/image-prompt-generator/SKILL.md` に従って画像プロンプトを作る。
6. Codex app-server / gpt-image-2 でラスター画像を生成する。
7. 成果物を案件フォルダ、`portfolio/`、または `exports/` に保存する。

## 注意

- 参考画像は構造・雰囲気・視線誘導のみ使う。
- 商標、実在人物、元コピーの再現は禁止。
- 文字切れ、可読性、余白、CTAの視認性を確認する。

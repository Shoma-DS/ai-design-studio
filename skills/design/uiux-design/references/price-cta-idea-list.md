# 価格・CTAボタン アイデア集

価格文字とCTAボタンを作るときに、手が止まったら上から眺めて選ぶためのリスト。
NotebookLM「LP制作リファレンス」にも同じ内容を登録済み（ソース名: 価格・CTAボタン アイデア集）。

---

## A. 価格の見せ方

| # | アイデア | 一言 | 使いどころ |
|---|---|---|---|
| A-01 | 単位を小さく | 「円」を数字の半分の大きさに落とす | 全案件 |
| A-02 | 数字だけ欧文 | 数字はHelvetica系、単位は和文。混植で数字が締まる | 全案件 |
| A-03 | 等幅数字 | 桁が揃って価格表の縦のラインが通る | 料金表・比較表 |
| A-04 | ¥マークに置き換え | 「円」より短くスッキリ。ページ内で表記を統一 | モダン・シンプル系 |
| A-05 | 税込を右下に小さく | 数字の半分以下で添える | 全案件 |
| A-06 | 税込を左上に小さく | 数字の前に置いて先に安心させる | 通販 |
| A-07 | 数字だけ色を変える | アクセント色を金額に集中させる | キャンペーン |
| A-08 | 斜体で勢いを出す | スピード感。落ち着いたトーンでは使わない | セール |
| A-09 | 打ち消し線で比較 | 通常価格を小さく打ち消し、矢印で現価格へ | 値引き訴求 |
| A-10 | OFF率の丸バッジ | 金額の左肩に重ねる | 通販 |
| A-11 | 期限バッジ | 「9/30まで」を丸や帯で。日付は実在するものだけ | キャンペーン |
| A-12 | 1回あたりに分解 | 「1回あたり2,500円」を小バッジで併記 | 定期・回数券 |
| A-13 | 背中押しの一言 | 「3人に1人が選んでいます」を金額の上に | 数字の裏付けがある時 |
| A-14 | 購入理由バッジ | 売上No.1／口コミ4.7／返金保証60日を丸で3つ | 根拠がある時 |
| A-15 | 割引率を主役に | 「90%OFF」を最大サイズ、実額は小さく添える | 低単価・お試し |
| A-16 | 3プラン横並び | 中央だけ大きく「1番人気」。プランは3つまで | サブスク・コース |

## B. CTAボタンの型

| # | 型 | 使いどころ |
|---|---|---|
| B-01 | 横長の角丸ブロック | 基本形。本文中・追従バー |
| B-02 | 正方形の縦積み（アイコン＋価格＋行動文） | バナー内・SNS広告・サイドバー |
| B-03 | 右端が尖った矢印形 | 次ページ誘導。進行感が強い |
| B-04 | 枠線タイプ | 背景が濃い面・副次CTA・落ち着いたトーン |
| B-05 | 二重枠（白フチ） | 写真や柄の上でもボタンが沈まない |
| B-06 | 点線のクーポン枠で囲む | クーポン配布。「自分宛て」の感じ |
| B-07 | 1段（行動文だけ） | オファーが無い案件。BtoB・士業・ブランド |

## C. CTAボタンの色

| # | 色 | 向く商材 |
|---|---|---|
| C-01 | 緑グラデ | 化粧品・サプリ・健康食品（申込色として定着） |
| C-02 | 赤 | クーポン・期間限定（緊急性が最も強い） |
| C-03 | ピンク | 女性向け・美容 |
| C-04 | オレンジ | 食品・日用品 |
| C-05 | ゴールド | 高価格帯・最安値保証。濃い背景で映える |
| C-06 | 黄×黒 | 金融・ポイント還元（可読性が最も高い） |
| C-07 | 黒地＋差し色 | 男性向け・ガジェット・SALE |
| C-08 | LINEグリーン #06C755 | 友だち追加 |

どの色でも、**ページ内でその色を使うのはCTAだけ**にする。

## D. ボタンに足すパーツ

| # | パーツ | メモ |
|---|---|---|
| D-01 | 上に吹き出し帯 | 返金保証・このページ限定・数量限定。下向き三角で接続 |
| D-02 | 肩の丸バッジ | %OFF・保証日数・先着人数。右上に半分はみ出させる |
| D-03 | 左端の縦バッジ | 「初回限定」を縦書き。横幅を食わない |
| D-04 | 左に丸い再生風アイコン | 動く・進む印象 |
| D-05 | 左に商品画像の切り抜き | 何を買うのか一目で分かる |
| D-06 | 右に人物写真 | 使用イメージとターゲットの明示 |
| D-07 | 「送料無料」を白チップで | 価格の隣に小さく |
| D-08 | 上半分の光沢 | 特別感。多用すると安く見える |
| D-09 | 光が走る動き | 視線を引く。`prefers-reduced-motion` で停止させる |
| D-10 | ボタン直下の注釈 | 定期の2回目以降の価格・解約条件。定期購入では必須 |

足すのは **2〜3個まで**。通販は多め、BtoBは0〜1個。

## E. 質感（ここが崩れると一気に安く見える）

| # | 層 | 実装 |
|---|---|---|
| E-01 | 外周の濃いフチ | 面より2〜3段暗い同系色を2〜3pxで回す |
| E-02 | フチと面の間の白い細線 | `inset 0 0 0 1px rgba(255,255,255,.8)` |
| E-03 | 面の二段グラデ | 上が明るく、中央で一段落とし、下へさらに沈める |
| E-04 | 上半分の薄い光沢 | 樹脂のような艶 |
| E-05 | 下辺の厚いソリッド影 | `0 4px 0` ＋ぼかし影。押すと沈む距離。発光影は使わない |
| E-06 | 細い袋文字 | `-webkit-text-stroke: 1.6px` ＋ `paint-order: stroke fill`。太いと駄菓子になる |
| E-07 | 1行で級数を混在 | 「初回」小チップ／金額 特大・黄／単位 中／「（税込）」極小 |
| E-08 | 色替えはセットで | 面・フチ・下辺影・袋文字の縁取りを同じ色相の濃い側で揃える |

## G. 使う前の確認

- [ ] A-09／A-10／A-15の二重価格表示は、その通常価格で相当期間実際に販売した実績があるかクライアントに確認したか（景品表示法の有利誤認）
- [ ] 期限は「本日限り」ではなく終了日を明記したか
- [ ] 「最安値」「日本初」等の最上級表現に根拠資料があるか
- [ ] タップ領域44px以上、文字と背景のコントラスト比4.5:1以上（`scripts/uiux-audit.mjs` で実測）
- [ ] hover／押下／focus-visible／送信中の4状態があるか
- [ ] 1画面に置くCTAは1種類か
- [ ] 丸ピル＋グロー影になっていないか

# バナー／FV の PSD 書き出し

**ステータス: 設計フェーズ（2026-09-08 時点で未検証）。** 実装・検証前にこのファイルの手順で通しテストを1枚行い、結果を反映してからクライアント納品に使う。

クライアントから「PSDで納品して」と言われたときに使う。求められているのは大抵、拡張子がPSDのファイルではなく **Photoshopで開いてテキストが打ち替えられる状態** なので、レイヤー分けを前提に進める。

## 前提と環境

- **Photoshop本体は未インストール**（Creative Cloud と Premiere Pro 2026 / Media Encoder 2026 はあり）。PSDの目視検証は [Photopea](https://www.photopea.com/)（ブラウザで動く無料PSDエディタ）で行う。
- PSDの生成は Node の **`ag-psd`** を使う。レイヤー構造・グループ・レイヤー名・編集可能テキストレイヤーに対応する。
- 画像生成は他のスキルと同じく Codex app-server / `gpt-image-2`（`server/codexImageClient.mjs`）。`refImages` に参照画像を渡せる。

## モードの選択

対象が「これから作るもの」か「すでにある1枚画像」かで、まったく別の作り方になる。

### モードA: 自社制作物（推奨）

こちらで画像を生成するので、**そもそも文字を焼き込まない**。推定が一切入らないため、モードBより精度が高く、劣化がない。

1. 構成とコピーを確定する（`banner-creator` / `lp-creator` の手順4まで）
2. `gpt-image-2` では **文字なしの背景プレート** だけを生成する。プロンプトに「テキスト・ロゴ・数字を一切描画しない」を明記し、文字が乗る領域には十分なネガティブスペースを確保させる
3. 見出し・サブコピー・CTA・装飾は、テキスト内容／座標／フォント／サイズ／字間／行間／色をデータとして保持する
4. `ag-psd` でレイヤーを組み立てて書き出す
5. 同じデータからPNG書き出し・サイズ違い展開（正方形／横長／縦長）も行う

副産物として、ABテスト用のパターン出しが自動化できる。

### モードB: 既存の1枚画像

過去に文字を焼き込んで作ったバナーや、クライアント支給の画像が対象。**元画像を剥がすのではなく、読み取って組み直す（再構築）**。

1. 画像を読み、テキスト内容・位置・サイズ・色・書体の系統（ゴシック／明朝／丸ゴシック等）・装飾（縁取り・影・グラデーション）を書き出す
2. 文字・ロゴを除いた背景を復元する。`gpt-image-2` に元画像を `refImages` で渡し、「文字を除去して背景を自然に補完する」指示で背景プレートを作る
3. 読み取った文字情報を、後述のOFLフォントでテキストレイヤーとして再現する
4. モードAと同じく `ag-psd` で書き出す

**限界を必ず伝える**: これは近似の再構築で、ピクセル単位で元画像と一致はしない。文字の背後が複雑な写真・グラデーションであるほど補完の粗が出る。納品前に元画像と並べて確認し、差が目立つ箇所は該当レイヤーだけ手当てする。

## レイヤー構成の基準

グループで分け、レイヤー名は日本語で内容が分かるようにする（クライアント側のデザイナーが開く前提）。

```text
バナー名.psd
├─ 装飾            （あしらい・図形・区切り線）
├─ CTA             （ボタン背景 / ボタン文字）
├─ テキスト        （見出し / サブコピー / 補足 / 注釈）
├─ ロゴ
├─ 写真・イラスト
└─ 背景            （ベタ塗り / グラデーション）
```

## フォントの扱い

再現に使うフォントは **OFL（SIL Open Font License）のもの** に限定する。クライアントが同じフォントを合法的に入手・使用でき、ライセンス上の問題が起きないため。

- 和文の候補: Noto Sans JP / Noto Serif JP / Zen Kaku Gothic New / Zen Old Mincho / M PLUS 1p / Shippori Mincho / Klee One
- 使用したフォントのファイルとライセンス全文を `fonts/` に同梱する
- 元画像が有償フォントで作られている場合、同一フォントの再現はしない。系統の近いOFLフォントで代替し、READMEに「元は別書体の可能性がある」旨を明記する

## 納品物

```text
<project>/psd/
  <name>.psd
  fonts/            使用フォント本体 + OFLライセンス全文
  README.md         レイヤー構成、編集手順、フォント差し替え方法、既知の制限
  preview.png       PSDから書き出した確認用画像
```

READMEには最低限これを書く: レイヤー構成の一覧、テキストの打ち替え方、フォントのインストール方法、モードBの場合は「再構築であり元画像と完全一致ではない」旨。

## 検証

納品前に必ず Photopea で実際に開き、次を確認する。

- テキストレイヤーがテキストとして選択でき、打ち替えられる
- レイヤー名・グループ構造が意図どおり
- フォントが正しく当たっている（未インストール時の代替表示になっていないか）
- 書き出した見た目が元のデザインと一致する

## 注意

- 参考画像は構造・雰囲気・視線誘導のみ使う。商標・実在人物・元コピーの再現は禁止（`banner-creator` と同じ）。
- クライアント支給画像をモードBでPSD化する場合、その画像の権利がクライアントにあることを確認してから作業する。

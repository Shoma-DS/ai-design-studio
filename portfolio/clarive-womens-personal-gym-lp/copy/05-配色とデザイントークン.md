## タイポグラフィ

| 用途 | フォント | 指定 |
|---|---|---|
| 見出し（和文） | Noto Serif JP | `700` — 明朝で品位を出す |
| 本文（和文） | Noto Sans JP | `400 / 500` |
| 数値・英字 | Jost（または system sans） | `500 / 600` — 実績数値に使用 |

- 見出しは明朝、本文はゴシックの組み合わせで「高級だが読みやすい」を両立
- 数値（−7.2kg、96%）のみ欧文フォントで組み、視認性と印象を上げる
- 行間: 見出し 1.4／本文 1.9（和文の可読性重視）
- 文字間: 見出し `0.04em`、本文 `0.02em`

## 形状・質感のルール（AIっぽさの回避）

| 禁止 | 代替 |
|---|---|
| ピル型（`border-radius: 999px`）のボタン | `border-radius: 4px` の角丸長方形 |
| ボタンの発光シャドウ（カラーグロー） | `box-shadow: 0 4px 16px rgba(0,0,0,.10)` の自然な影 |
| 円形アイコンチップのバッジ | 番号を明朝の大きな数字で直に置く／細い罫線の矩形 |
| 紫〜青のグラデーション | 単色、または同系色のごく浅いグラデーション |
| 過度なガラスモーフィズム | 不透明の面 ＋ 1px の罫線 |

- 角丸は `4px`（ボタン・入力欄）と `2px`（カード）に統一
- 影は最大 `0 8px 24px rgba(27,24,24,.10)` まで
- 区切りは太い色帯ではなく `1px` の罫線と余白で作る

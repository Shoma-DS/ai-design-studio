# セクション構成・ワイヤーフレーム｜CLARIVE 渋谷店 LP

作成日: 2026-08-02
構成方式: ハイブリッド（AI生成の写真ビジュアル ＋ HTML/CSS/JSのテキスト・UI）

---

## 構成方式の判断

| 要素 | 実装 | 理由 |
|---|---|---|
| 人物・内観・食事・ビフォーアフターのビジュアル | **AI生成画像**（Codex / gpt-image-2） | 撮影素材の代替。世界観の統一が必要 |
| すべてのテキスト（見出し・本文・価格・FAQ） | **HTML/CSS** | 日本語の可読性を確保。画像に焼き込むと文字が崩れ、修正コストも高い |
| CTAボタン・追従バー・ナビ | **HTML/CSS/JS** | 実際に押せる必要がある |
| FAQアコーディオン・お客様の声カルーセル | **HTML/CSS/JS** | 状態を持つUI |
| ビフォーアフター比較スライダー | **HTML/CSS/JS** | ドラッグで比較させる |
| 説明動画 | **HTML `<video>`** | Premiere Proで書き出したmp4を埋め込む |
| スクロールアニメーション・カウントアップ | **JS（IntersectionObserver）** | — |

## アニメーション設計

| 対象 | 挙動 | 実装 |
|---|---|---|
| 全セクション | スクロールで下から16pxフェードイン | IntersectionObserver `.reveal` |
| stats 数値 | 画面内に入ったら0からカウントアップ（1.6秒） | JS `requestAnimationFrame` |
| reasons カード | 100msずつ遅延して順に出現 | `--delay` CSS変数 |
| ヒーロー背景 | ゆっくりズームイン（8秒・1.0→1.06） | CSS `@keyframes` |
| ヒーローCTA | 読み込み後に浮き上がり | CSS animation |
| CTAボタン | ホバーで浮き上がり＋影／光沢スイープ | CSS `:hover` |
| ビフォーアフター | ドラッグでスライダー移動 | JS pointer events |
| お客様の声 | 矢印・ドットで切替、スワイプ対応 | JS |
| FAQ | 開閉（高さアニメーション） | JS + `grid-template-rows` |
| 追従CTAバー | ヒーローを抜けたら下からスライドイン | IntersectionObserver |
| ヘッダー | 下スクロールで隠れ、上スクロールで再表示 | JS |

**`prefers-reduced-motion: reduce` の場合、すべてのアニメーションを無効化する。**

## 遷移先・計測（実案件時に差し替え）

- CTAボタン → ページ内の予約フォーム（`#cta`）へスムーススクロール
- フォーム送信先は未接続（`preventDefault` でサンクスメッセージ表示のデモ動作）
- 実案件では予約システム（RESERVA / STORES予約 等）または自社フォームへ接続する

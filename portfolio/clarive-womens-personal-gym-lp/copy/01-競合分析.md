## 1. 市場の構造

渋谷のパーソナルジム市場は、大きく4つの層に分かれている。

| 層 | 価格帯（2ヶ月16回目安） | 代表的なポジション | 主なターゲット |
|---|---|---|---|
| **A. ハイエンド総合型** | 50〜70万円 | RIZAP など。圧倒的な認知とCM投下量、返金保証を業界に定着させた層 | 予算に余裕があり「確実性」を買う層 |
| **B. 中価格帯 大手チェーン** | 25〜40万円 | 24/7Workout、BEYOND、チキンジム など。店舗数と通いやすさで勝負 | コスパ重視、男女混合 |
| **C. 女性特化型** | 20〜35万円 | Reborn myself、OUTLINE、CREBIQ など。女性トレーナー・女性専用空間を訴求 | 男性の視線が苦手／産後・ホルモン周期の悩みを持つ層 |
| **D. 低価格・都度払い型** | 月2〜5万円 | かたぎり塾、地域個人ジム | 継続前提で価格を抑えたい層 |

**CLARIVEが取るべきポジション = C層の中で「保証」と「食事の現実性」を上乗せした上位**。
A層の返金保証という安心材料を、C層の価格帯とC層の女性専用環境で提供する、という座組み。

## 2. 主要競合3タイプの訴求分析

### 競合タイプ① ハイエンド総合型（RIZAP型）

| 項目 | 内容 |
|---|---|
| 強み | 圧倒的認知、ビフォーアフターの物量、30日全額返金保証、結果へのコミット姿勢 |
| 弱み | 価格が心理的障壁。「厳しそう」「食事制限がつらそう」というイメージが定着。男性色が強い |
| LPの型 | 巨大なビフォーアフター → 実績数値 → 保証 → 料金 → 無料カウンセリング |
| CTA | 「無料カウンセリングに申し込む」固定バー＋複数箇所 |

**学ぶ点**: ビフォーアフターを1枚ではなく「量」で見せる。保証を早い段階（ファーストビュー直下）で提示して価格不安を先回りする。
**差別化点**: 「厳しい・つらい」の裏返しを取りに行く。CLARIVEは「食べながら」「女性トレーナーだから相談しやすい」を前面に。

### 競合タイプ② 中価格帯チェーン（24/7Workout型）

| 項目 | 内容 |
|---|---|
| 強み | 価格の納得感、店舗数、手ぶらOKなどの利便性訴求 |
| 弱み | 男女混合で、女性からは「男性トレーナーに体型を見られるのが嫌」という離脱要因 |
| LPの型 | 価格の安さ → 利便性（手ぶら・駅近） → トレーナーの質 → CTA |
| CTA | 価格の直後に集中配置 |

**学ぶ点**: 「手ぶらでOK」「駅から◯分」などの障壁除去コピーは、行動を決める最後のひと押しとして効く。
**差別化点**: 女性専用・完全個室を「利便性」ではなく「安心」の軸で立てる。

### 競合タイプ③ 女性特化型（Reborn myself／OUTLINE型）

| 項目 | 内容 |
|---|---|
| 強み | 女性トレーナー、女性専用、部分痩せ・産後ケアなど女性の悩みに特化した訴求 |
| 弱み | 「女性専用」だけでは差別化しきれず横並びになりがち。保証を持たない店舗が多く、価格への不安が残る |
| LPの型 | 悩み共感 → 女性トレーナー紹介 → ビフォーアフター → 料金 → CTA |
| CTA | 悩み共感セクションの直後に第1CTAを置く傾向 |

**学ぶ点**: 悩み共感セクションの解像度がそのままCVRに直結する。「痩せたい」ではなく「去年買ったデニムが入らない」レベルまで具体化している店舗ほど強い。
**差別化点**: **返金保証**を持つ女性専用ジムは少ない。ここがCLARIVE最大の武器。

## 3. 競合LPに共通する「型」（踏襲すべき王道）

1. ファーストビューで**ビフォーアフター or 数値実績**を必ず見せる
2. ファーストビュー直下に**無料カウンセリングCTA**（迷わせない）
3. **悩みの言語化**セクションで「自分のことだ」と思わせる
4. **選ばれる理由**を3〜5個、アイコン付きで整理
5. **料金は隠さない**（隠すLPは離脱率が高い）
6. **お客様の声＋ビフォーアフター**で証明
7. **よくある質問**で最後の不安（続くか／食事／勧誘）を潰す
8. **スマホ下部に追従CTAバー**（スマホ流入が7〜8割のため必須）

## 4. 競合LPに共通する「弱点」（CLARIVEで潰す）

| 競合の弱点 | CLARIVEでの打ち手 |
|---|---|
| ビフォーアフターが加工っぽく信用されない | 「※効果には個人差があります」を明記し、平均値（−7kg）を主役にする。誇張しない誠実さを差別化に転換 |
| 「食事制限がつらそう」が最大の離脱要因 | 「糖質ゼロを強制しない」「外食・コンビニOK」を食事指導セクションの見出しに置く |
| 料金ページで金額だけ見て離脱 | 料金の直下に「返金保証」と「1日あたり◯円」の分解を置き、金額の心理的インパクトを緩和 |
| カウンセリングの勧誘が怖くて予約できない | FAQに「無理な勧誘は一切しません」を明記。CTAボタン付近にも小さく添える |
| 男性トレーナーへの抵抗 | 女性トレーナーのみ、を第一の理由として最上位に配置 |

> **渋谷で「食べながら2ヶ月−7kg」を、女性トレーナーと完全個室で。結果が出なければ返金します。**

## 7. 広告クリエイティブ（15秒動画）への示唆

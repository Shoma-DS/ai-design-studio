# ヒーロー背景映像 編集設計｜CLARIVE

作成日: 2026-08-03
用途: LPのファーストビュー背景（PC 1920×1080 / スマホ 1080×1040）

---

## 方式を変更した理由

初版は「ダンベルカール1レップを16コマの静止画として生成し、オプティカルフロー補間で連続動作にする」方式だった。これは**破綻した**ため廃止する。

**破綻の内容**: 連続フレームを並べると、腕だけでなく胴体の太さ・脚の位置・背景のダンベルラック・観葉植物までがフレームごとに微妙にずれて揺れていた。

**原因**: AI生成の静止画は、同じ参照画像・同じプロンプトを与えても毎回わずかに違う絵として描かれる。画素レベルでは一致しないため、補間アルゴリズムがその差も「動き」として引き伸ばし、人体がぐにゃりと変形して見える。**静止画生成で連続的な手足の動きを作る限り、この揺れは原理的に消せない。**

**新方式**: 連続動作の偽装をやめ、**構図の違う4カットをディゾルブで繋ぐ編集**にする。カット間で絵が変わるのは「編集」として自然に受け取られるため、揺れの問題が発生しない。写真素材で映像を作るときの定石。

## 素材

`ad/hero-shots/` に4点（すべて 1672×941 / 16:9 / 左55%は無地の壁）

| ファイル | 内容 | 役割 |
|---|---|---|
| `shot-01-curl.png` | 全身。カールのトップ、胸の高さでダンベル保持 | つかみ。何のジムか一目で分かる |
| `shot-02-close.png` | バストアップの寄り。集中した表情と上腕の緊張 | 本気度・熱量を伝える |
| `shot-03-trainer.png` | 女性トレーナーがフォームを見ている引き | マンツーマン・女性トレーナーの訴求 |
| `shot-04-room.png` | 個室の引き。人物は小さく、窓の光 | 完全個室・空間の上質さ。呼吸を作る |

## タイムライン（PC版 1920×1080 / 30fps / 12秒 / 無音 / ループ）

| # | カット | イン | アウト | 尺 | モーション |
|---|---|---|---|---|---|
| 1 | shot-01-curl | 0:00 | 0:03 | 3.0s | スケール 100→104%、中心 右寄り |
| 2 | shot-02-close | 0:03 | 0:06 | 3.0s | スケール 104→100%（引き） |
| 3 | shot-03-trainer | 0:06 | 0:09 | 3.0s | スケール 100→103%、わずかに右へパン |
| 4 | shot-04-room | 0:09 | 0:12 | 3.0s | スケール 103→100%（引き） |

- **トランジション**: 各カット間にクロスディゾルブ **20フレーム（約0.67秒）**。カット4の終わりからカット1の頭へも同じディゾルブを掛け、ループの継ぎ目を消す
- **ループ処理**: カット1の頭をタイムライン末尾にもう一度置き、その上で20フレームのディゾルブを掛けてから、重複分をトリムする
- **モーションの方向を交互にする**（寄り→引き→寄り→引き）ことで、単調さを避け、かつ次のカットへの繋がりが滑らかになる
- テロップ・ロゴ・図形は**一切入れない**（テキストはLP側のHTMLで重ねる）

## スマホ版 1080×1040 / 30fps / 12秒

同じタイムラインを、各カットの**右45%（人物がいる側）を1:1に近い比率で切り出して**構成する。左の余白はスマホでは不要（コピーは写真の上ではなく上部に別途置くレイアウトのため）。

## 書き出し

| 出力 | 仕様 |
|---|---|
| `lp/video/hero-pc.mp4` | H.264 / 1920×1080 / 30fps / 音声なし / 2.5MB以内 |
| `lp/video/hero-pc.webm` | VP9 / 同上 |
| `lp/video/hero-sp.mp4` | H.264 / 1080×1040 / 30fps / 音声なし / 1.5MB以内 |
| `lp/video/hero-sp.webm` | VP9 / 同上 |
| `lp/video/hero-pc-poster.jpg` / `hero-sp-poster.jpg` | 各先頭フレーム |

ポスターは必ず動画の先頭フレームにする（別画像だと、LPで動画へ切り替わる瞬間に構図が跳ねる）。

## メインペルソナ（LPの主語はこの人）

### 佐藤 あかり｜32歳・広告代理店 アカウントプランナー

| 項目 | 内容 |
|---|---|
| 居住／勤務 | 目黒区在住／勤務先は渋谷。通勤経路上にジムがあることが必須条件 |
| 年収 | 520万円。自由に使えるお金は月6〜8万円 |
| 家族 | 独身、彼氏あり。来年に結婚の話が出ている |
| 体型 | 158cm／58kg。1年半で6kg増えた。学生時代は48kgだった |
| 生活 | 出社は週3。20時退社が基本だが繁忙期は23時。会食が月4〜6回 |

**きっかけ（トリガー）**
友人の結婚式で撮った写真を見て、自分だけ二の腕と背中の肉が写り込んでいたことにショックを受けた。式は半年後にもう1件ある。

**インサイト（本音）**
- 「痩せたい」というより「あの写真の自分に戻りたくない」
- ジムに行く時間がないのではなく、**続く自信がない**
- 過去に糖質制限で1ヶ月−4kg → 反動で+5kg。「もうあの反動は嫌」
- 会食を断れない立場なので、**外食NGのプランは最初から選択肢に入らない**

**不安・障壁**
1. 男性トレーナーに体を触られる／見られるのが本当に嫌
2. 30万円前後という金額。「効果がなかったら」が怖い
3. 大部屋で他の会員に見られながら追い込まれるのが恥ずかしい
4. カウンセリングで強引に契約させられそう

**刺さるコピーの方向**
- ×「本気で痩せたいあなたへ」→ 精神論は響かない
- ○「会食を断らずに、2ヶ月で−7kg」→ 生活を変えずに済む示唆
- ○「トレーナーは全員女性です」→ 一番の障壁を最初に外す
- ○「結果が出なければ、全額返金します」→ 金額の不安に対する回答

**このペルソナがLPで見たい順序**
渋谷／女性専用だと分かる → 自分の悩みが書いてある → 女性トレーナーだと分かる → 食事が現実的だと分かる → 実際に痩せた人がいる → 料金と保証 → 勧誘されないと分かる → 予約

## 「誰に向けないか」の定義

- ボディメイク大会・コンテスト出場を目指す層 → 訴求が変わるため対象外
- 男性 → 女性専用のため対象外
- 短期集中ではなく月額で長く通いたい層 → 別プランの導線として扱い、LPの主訴求には置かない

この線引きにより、LPのコピーを「2ヶ月・結果・女性専用」に集中させる。

# 参考画像分析と制作設計

## 参考画像分析

- 配色: 白〜ごく淡いミントを広いベースにし、主見出しの鮮緑、速報感を出す赤、限定感を出す黄緑、補助訴求のピンク、円形バッジのオレンジを局所的に使用。彩度の高い色は文字とバッジに限定され、商品写真は低彩度。
- フォント: 太い角ゴシックを主体とし、速報見出しには明朝系の強い縦線・ウロコ感を混ぜている。親しみのある短い擬態語は丸みのある手書き風。
- 文字組: 右下の二段大見出しが最大。上辺の速報、中央上の円形バッジ、右上の斜めリボン、右中の斜めピンク文字を順に小さく配置し、サイズ差を明快にしている。
- 余白: 商品写真の上と右側に文字を置くための白場を確保。各要素の周囲は詰めすぎず、背景の白を装飾として使っている。
- 視線誘導: 上辺の赤い速報 → オレンジ円 → 緑リボン → ピンクの補助訴求 → 右下の大見出し → 左下の商品写真。色相差と斜め要素で視線を右下へ運ぶ。
- レイアウト: 左下に大きな商品、右下に主見出し、上部に短い速報とバッジを置く非対称構成。商品と主見出しの面積がほぼ拮抗し、二つを主役として結びつける。
- 装飾要素: 円形吹き出し、斜めリボン、細い緑のコーナー罫線、小さな三角矢印。装飾は販促情報のまとまりを作るためにだけ使われる。
- 写真の使い方: 開封したジェル容器を斜め上から近接撮影。左・下を大胆にトリミングし、透明感のあるジェルの艶を見せる。背景との境界は柔らかく、写真の圧迫感を抑えている。
- 世界観: ドラッグストア系スキンケアの親しみ、即効感、みずみずしさ、期間限定の高揚感。高級感よりも「分かりやすさ」と「今すぐ試したい勢い」を優先。
- 再現ポイント: 444:373の比率、左下約55%を占める近接商品、右側の大見出し、上部の白場、鮮色を文字・バッジに限定すること。情報量を増やさず、主役を商品と「濃密保湿」の二点に絞る。

## ターゲット分析

- 想定ターゲット: 20〜40代、べたつかない保湿を探す女性。夏の冷房乾燥や入浴後の時短ケアが気になる層。
- インサイト: 軽い使用感は欲しいが、保湿力は妥協したくない。見た瞬間にテクスチャーと使用後の肌感を想像できることが重要。
- 行動障壁: ジェルは保湿力が弱そう、似た商品が多く違いが分かりにくい。
- 有効な訴求: 「濃密」「ぷるん」「キュッと引き締め、うるおい肌へ」の短い感覚語で、保湿力と使用感を同時に伝える。

## レイアウト設計

- アートボード: 888×746px（参考画像444×373pxの2倍、同一比率）
- 商品: x=0〜480、y=265〜746。左下で画面外へトリミング。
- ブランド・速報: 上端24〜82px。横一列で入口を作る。
- 擬態語: 左上110〜200px。商品テクスチャーへ視線を落とす。
- 円形バッジ: 中央上 x=302〜514、y=118〜330。
- リボン: 右上 x=570〜874、y=100〜190、約-11度。
- 季節訴求: 右中 x=646〜850、y=210〜330、約10度。
- 主見出し: 右下 x=392〜858、y=350〜616。最も大きく、二段で配置。
- ベネフィット: x=390〜846、y=640〜702。主見出しを受ける一行。

## 自己レビュー基準

- CTR: オレンジ・緑・ピンクの三色アクセントでスクロール中の停止力を確保し、「数量限定」「濃密保湿」を短時間で認識できること。
- 視認性: 背景写真を低彩度・高明度にし、主見出しを鮮緑＋白フチで分離する。
- 可読性: 文字は最大7ブロックに抑え、長文を置かない。小さいブランド表記以外はスマホ縮小でも判別できる太さにする。
- 訴求力: 商品の透明ジェルと「濃密保湿」を同時に見せ、テクスチャーとベネフィットの対応を明確にする。

## 改善案

1. 実運用時は媒体別に1:1と1.91:1へ展開し、主見出しの改行位置だけを最適化する。
2. A/Bテストでは「数量限定!」を「今だけ増量!」へ差し替え、限定性と具体的便益のどちらがCTRへ効くか比較する。
3. 実商品を使う場合は容器ラベルを正規データへ置換し、薬機法・景品表示法に沿って効能表現を最終確認する。

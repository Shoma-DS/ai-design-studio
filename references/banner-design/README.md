## 制作前チェックリスト（企画・戦略）

- 伝えたい内容を一つに絞る（詰め込みすぎない）
- 掲載場所・サイズを先に確認する（HP設置用かWeb広告配信用かで規定が異なる）
  - メインビジュアル内目安: 1,200×500〜800px
  - サイドバー内目安: 300×250〜600px
  - フッター内目安: 1,200×200〜300px
- ターゲット層を想定し、誰が見ても分かる内容にする
- 複数バナーを並べる場合は色で差別化し識別性を確保する
- 設置先ページの背景色・デザインとの統一感を考慮する
- ABテスト前提で複数パターンを用意し、一要素ずつ検証する

## 素材・配色

- 高解像度の画像を使い、コンテンツイメージと写真の内容を一致させる
- 背景にテキスト配置スペースを確保する
- ブランドイメージに合った配色を基本に、セール感を出したい場合は赤・黄色などの注意色を活用
- テキストと背景のコントラストを確保する
- シリーズものは配色・レイアウトに規則性を持たせる

## 文字・キャッチコピー

- フォントは2〜3種類までにまとめる
- 文字サイズで情報の優先度を表現する（本文は左揃え基本）
- 拡大・縮小時に比率を歪ませない
- 「詳細はこちら」「今すぐ購入」などクリックを促すキラーワードを入れる
- 無料・限定・実績数値など反応されやすい言葉を使う
- No.1表現を使う場合は調査機関名・調査年月の明記が必須
- 虚偽・誇張表現、法的規制（景表法など）に抵触しないか確認する
- 人物写真は肖像権・利用規約を確認する

## レイアウト・視線誘導

- 余白を活かし、情報を詰め込みすぎない
- 情報の階層構造（見出し→補足→CTA）を明確にする
- ユーザーの行動フロー（認識→クリック→遷移先で満足）を意識し、リンク先ページとデザインの統一感を持たせる

## 最終確認

- 実際の表示サイズ・モバイル表示で文字の潰れや視認性を確認する
- 誤字脱字、情報の欠落がないか複数人で確認する
- 画像サイズ・ファイル容量がページ読み込み速度に影響しないか確認する
- 広告媒体のポリシー・審査基準（ロゴ重ね表示禁止など）を確認する

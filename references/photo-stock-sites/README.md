# 写真素材・参考画像サイト

LP/HP/バナー/サムネ制作時に、雰囲気・構図・光の当たり方などを参考にするための外部写真サイトまとめ。
AGENTS.mdのルール通り、画像生成は必ずCodex app-server経由のgpt-image-2で行う。ここに挙げるサイトの写真は
そのまま使わず、あくまで「構造・雰囲気・視線誘導」の参考として見る（コピー・トレース・商標再現は禁止）。

## 参照元

- Food.foto.ne.jp https://food.foto.ne.jp/ — 料理・食材のフリー写真素材。飲食系LP/バナーの湯気・質感・盛り付け構図の参考に。
- Kaboompics https://kaboompics.com/ — ライフスタイル・インテリア・ワークスペース・美容系のフリーストックフォト。北欧系の明るいトーンや小物の配置が豊富。
- Public Domain Image Archive https://pdimagearchive.org/ — パブリックドメインの写真・アート素材アーカイブ。歴史的資料やクラシックな構図の参考に。
- Sky Seeker https://www.skyseeker.net/ — 空・雲のフリー写真素材。ヒーローセクションの背景やパララックス演出の空の質感参考に。

## 使い方

- 生成画像プロンプト作成前に、該当ジャンル（食材/ライフスタイル/空背景など）に近いサイトを開いて構図・光・色味を確認する。
- 気に入った参考画像は案件フォルダの `references/`（`skills/design/lp-creator/SKILL.md` の「保存先」参照）にスクリーンショットで保存し、gpt-image-2への入力プロンプトで「構造・雰囲気のみ抽出」と明記して使う。
